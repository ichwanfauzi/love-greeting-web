# 💌 Love Greeting Web

> Aplikasi web interaktif berbasis animasi CSS dan JavaScript untuk menyampaikan ucapan, pesan apresiasi, atau kartu ucapan digital secara personal dan kreatif.

---

## 🌟 Fitur Utama

- 💌 **Kartu Ucapan Interaktif:** Efek membuka amplop/kartu ucapan saat tombol atau elemen diklik.
- 🎨 **Animasi & Efek Visual:** Tampilan dinamis dengan efek animasi CSS yang halus dan responsif.
- 🎵 **Latar Musik (Audio Player):** Pemutaran musik latar otomatis atau interaktif saat kartu dibuka.
- 📱 **Mobile Friendly:** Antarmuka yang dioptimalkan untuk tampilan layar *smartphone*.

---

## 🛠️ Tech Stack

- **HTML5** - Struktur halaman web
- **CSS3** - Animasi, transisi, dan *styling* responsif
- **JavaScript (Vanilla JS)** - Logika interaksi pengguna dan pengontrol audio
